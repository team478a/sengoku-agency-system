# 管理画面サイドメニュー整理

Version: 3.6.137
Date: 2026-08-03

## 実装内容

- 管理画面のサイドメニューを用途別の折りたたみグループに整理しました。
- ダッシュボードだけを常時表示し、以下のグループに分類しました。
  - 代理店・申請管理
  - LP・告知管理
  - 成果・問い合わせ
  - 外部連携
  - 共通顧客HUB
  - 運用・設定
- 現在表示中のページが含まれるグループは自動で開きます。
- 低頻度で直接開く必要が少ない「共通ID連携」「HUB修正」はサイドメニューから外しました。

## 補足

画面自体は削除していません。
共通ID連携やHUB修正は、関連するHUB画面や設定画面から辿る運用を想定しています。

なし。
