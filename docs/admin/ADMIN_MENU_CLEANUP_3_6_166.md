# 管理画面メニュー整理メモ

Version: 3.6.166

## 目的

管理画面のサイドメニューが増えてきたため、利用目的ごとに名称を整理しました。

機能自体は削除せず、運用者が迷いにくい表示名へ変更しています。

## 変更内容

| 変更前 | 変更後 |
| --- | --- |
| 成果・問い合わせ | 成果・報酬 |
| 報酬CSV | 報酬CSV取込 |
| 外部連携 | 外部サービス連携 |
| 連携セットアップ | かんたん連携設定 |
| 連携ガイド | 開発者向けガイド |
| 連携先管理 | 連携先一覧 |
| 共通顧客HUB | 顧客・購入権限 |
| 顧客HUB | 顧客一覧 |
| 共通ID検索 | ID紐づけ検索 |
| 購入権限 | 購入・利用権 |
| 送信待ち | 外部送信待ち |
| HUB確認 | 顧客HUB確認 |
| SSO連携 | 外部ログイン連携 |

## 方針

- 日常的に使う機能を上に置く
- 技術者向けの名称は、必要な箇所だけに残す
- 外部連携、共通ID、SSOは分けすぎず、用途で探せる名前にする
- 機能を非表示・削除する場合は、運用で使っていないことを確認してから行う

## 次に整理する候補

- 外部連携ログ、外部送信待ち、顧客HUB確認を「運用チェック」画面からまとめて見られるようにする
- 開発者向けガイドは、通常運用では使用頻度が低いため、将来的には「外部サービス連携」画面内のリンクに集約する
- 一斉メール送信は利用頻度に応じて、成果・報酬側または運用・設定側のどちらに置くか再確認する
