# 親子紐づけ変更機能

## 目的

代理店の登録後に、紹介者・上位代理店の紐づけ間違いが判明した場合に、管理者が後から正しい上位へ変更できるようにする機能です。

例:

- BさんがAさん配下になっている
- 実際はCさん配下だった
- 管理者がBさんの上位をCさんに変更する

## 画面

管理画面の左メニューから以下を開きます。

- 代理店管理
- 親子紐づけ変更

URL:

```text
/admin/agent_parent_links.php
```

メンバー管理画面の一覧にある「親子変更」ボタンからも、この専用画面を開けます。

親子紐づけの変更は専用画面に集約し、変更履歴・組織図・外部連携ログを同じ流れで確認できるようにしています。

## 変更できる内容

この画面で変更するのは `agents.parent_id` のみです。

以下は変更しません。

- 権限区分
- LP URL
- テンプレート
- 通知設定
- ログイン情報
- プロフィール情報

## 変更ルール

- エージェントは本部直属のため、上位変更対象外です。
- ディレクターの上位はエージェントのみ選択できます。
- アドバイザーの上位はディレクターまたはエージェントを選択できます。
- 自分自身を上位にすることはできません。
- 自分の配下メンバーを上位にすることはできません。
- 停止中のメンバーは上位候補に表示されません。

## 変更前の影響範囲確認

一覧の「影響範囲」には、変更対象者を起点にした以下の情報が表示されます。

- 直下人数
- 全配下人数
- 対象者と配下を含むPV数
- 対象者と配下を含む問い合わせ数
- 未対応問い合わせ数

親子紐づけを変更すると、組織図・代理店活動・下位代理店の集計・外部連携先の階層情報にも反映されます。
変更前に影響範囲を確認し、必要に応じて変更理由を入力してください。

## 履歴

変更時には `admin_action_logs` に以下を記録します。

- 操作種別: `parent_update`
- 対象メンバーID
- 変更前の上位
- 変更後の上位
- 対象の区分レベル
- 変更理由
- 操作管理者
- IPハッシュ

履歴は以下から確認できます。

```text
/admin/action_logs.php?action_type=parent_update
```

変更完了後の画面にも「変更履歴を見る」ボタンが表示されます。

## 外部連携

変更後に以下イベントで外部連携先へ同期します。

```text
parent_updated
```

外部システム側では、代理店の親子関係が変更されたイベントとして扱ってください。

外部連携ログは以下から確認できます。

```text
/admin/integration_logs.php?event_type=parent_updated
```

変更完了後の画面にも「外部連携ログを見る」ボタンが表示されます。
送信失敗だけを確認したい場合は以下を開きます。

```text
/admin/integration_logs.php?event_type=parent_updated&direction=outbound&success=0
```

外部連携ログ画面では、`parent_updated` の確認ショートカットから成功・失敗のログを確認できます。
失敗ログがある場合は、外部連携先の設定や接続状況を確認したうえで、ログ画面から再送を行います。

## 組織図での確認

組織図では、代理店をクリックすると右側に詳細が表示されます。

詳細では以下を確認できます。

- 区分
- コード
- 状態
- 直下人数
- 全配下人数
- PV
- 問い合わせ
- 未対応問い合わせ
- LP URL

詳細パネルから、LP URLコピー・問い合わせ一覧・メンバー編集・親子変更へ移動できます。
親子紐づけ変更後は、組織図で表示位置と配下人数が変わっているか確認してください。

## 整合性チェック

画面上で以下の不整合を検出します。

- エージェント以外で上位が未設定
- 区分に合わない上位が設定されている
- 自分自身または配下メンバーを上位にする循環

不整合がある場合は、画面上部の「整合性チェック」で件数を確認し、対象者の紐づけを修正してください。

## DB変更

この機能追加によるDBスキーマ変更はありません。
