# 管理画面サイドメニュー整理メモ

作成日: 2026-08-17

## 目的

管理画面のサイドメニューが増えすぎて目的の画面を探しにくくなっていたため、用途別に整理しました。

## 変更内容

- 代理店関連は「代理店管理」に集約しました。
- LP、プロジェクト、素材、成果分析は「LP・プロジェクト」に集約しました。
- 外部連携は、初期設定で使う「連携セットアップ」、説明用の「連携ガイド」、詳細管理用の「連携先管理」に整理しました。
- 共通ID関連は「共通顧客HUB」にまとめ、通常運用で使う画面だけを前面に残しました。
- ログ、チェック、送信待ち、スタッフ、SSO、アップデートなどは「運用・設定」にまとめました。
- 「一斉メール送信」は告知用途から運用用途へ移動しました。
- 共通ヘッダー内に残っていた文字化けコメントを読みやすい英語コメントへ修正しました。

## 削除ではなく移動した主なメニュー

- 一斉メール送信: 「LP・プロジェクト」から「運用・設定」へ移動
- 外部連携ログ: 「外部連携」から「運用・設定」へ移動
- SSO連携: 「外部連携」から「運用・設定」へ移動
- HUB確認: 「共通顧客HUB」から「運用・設定」へ移動

## 確認結果

- `admin/header.php` のPHP構文チェックは正常です。
- `admin/header.php` 内の文字化けコメントは検出されません。
