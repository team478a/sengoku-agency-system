# 外部連携ウィザード UI整理・接続テスト文言改善

Version: 3.6.136
Date: 2026-08-03

## 実装内容

- 外部連携ウィザードの接続テスト結果を原因別の日本語メッセージに変更しました。
- HTTP 401/403、404、405、422、500系、通信不可を分けて表示します。
- 初回登録フォームから、通常運用では迷いやすい「状態」「表示順」を非表示にしました。
- 登録済み連携先一覧から長い送信先URL表示を外し、前回テスト結果を確認できる表示に整理しました。
- 停止、表示順、送信先URLの個別変更は詳細設定画面に残しています。
